# Glossary — human-readable

Agents do not treat this file as living-knowledge.

- Features.md. Single file that holds the current state of features. No separate ticket files. No kanban board.
- Living-knowledge. Files under `/app-name-1/living-knowledge/`. Workers do not write them.
- Design spec. Phase 1 document. Only DesignArchitect-warm and the human write it.
- Warm. DesignArchitect-warm. Resume the same session when you can.
- Cold. Worker-cold. New session each assignment.
