# Worker-cold — human guide

What it is for: implements features you explicitly ask it to implement. Cold session.
What it is not for: writing living-knowledge, the design spec, or starting implementation when you only asked for a discussion.

How to start: new session each assignment. Tell it to read `.grok/agents/worker-cold.md`.
What it may write: code, commits. It changes a feature status in features.md only when you ask it to implement or when you signal done.
What it must never write: living-knowledge, the design spec.

Good first message: "Read `.grok/agents/worker-cold.md` and discuss the login feature."
Bad first message: "Discuss the login feature and then start coding it."
