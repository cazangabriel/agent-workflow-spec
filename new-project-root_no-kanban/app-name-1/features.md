# Features

Single file that holds the current state of features. One feature per entry. No separate ticket files. No kanban board.

Status values: to-do, in-progress, blocked, done.

A feature moves from to-do to in-progress only when the human asks Worker-cold to implement it.
A feature moves to done only when the human signals it is done.
If the human asks an agent to discuss a feature, the agent discusses it and does not change its status or start implementation.
