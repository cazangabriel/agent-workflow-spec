# Living-knowledge header

Every living-knowledge file starts with this header. The header is the only place the ownership and status rules are stated.

```markdown
# <filename>

**Status:** draft | accepted
**Owner:** DesignArchitect-warm | KanbanMaster-cold
**Last written by:** <role>
**Human must approve before agents treat as source of truth:** yes

Workers never write living-knowledge. They comment on the ticket and stop.
```
