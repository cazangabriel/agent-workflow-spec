# Vocabulary package

A + B + DDD extra.

A is one vehicle language (default English unless the human sets another).
B is ubiquitous language enforced inside each bounded context: no private synonyms for the same concept inside one context.
DDD extra is explicit boundary maps when two contexts use the same word for different things.

Module and layer expansions come only from abbreviations.md column Unabbreviated, written by DesignArchitect-warm.
Kind is fixed: F = Feature, TA = TechnicalArchitecture.
